# Information architecture

What Trama shows and how the user moves through it. This document covers the
**MVP** only and says nothing about visual style, which is described in the
[visual direction](visual-direction.md). Phases refer to the [MVP phases](../vision.md#mvp).

## Objects

| Object | What it is | Created by | Phase |
|--------|------------|------------|-------|
| **Source** | A meeting (two-track transcript), a note or a document. Stored as it is, never modified | The user: records, writes, imports | 1 (documents: 3) |
| **Summary** | A short summary, a title and key points for each source, generated through the provider | Trama | 1 |
| **Project** | The main unit of knowledge, with its own page | The curator | 2 |
| **Person** | A page with role, projects, actions and where the person is mentioned | The curator | 2 |
| **Decision, action, requirement, open question, term** | The items inside pages, each citing its source | The curator | 2 |
| **Doubt** | A question from the curator, with options and evidence, answered with one click | The curator | 2 |
| **Change** | An entry in the history: what changed, why and from which source. Can be undone | The curator | 2 |
| **Conversation** | A chat with citations | The user | 3 |
| **Settings** | Providers, model per task, transcription, recording, data | The user | 1 |

Rules:

- **No mandatory area.** A source belongs to zero, one or more projects. A source
  without a project is not lost: it stays searchable, feeds person pages and is
  available to the chat and to agents. If a matching project appears later, the
  curator links it.
- **Actions are managed by the curator.** It opens and closes them from what is said
  in sources, and every change is logged and can be undone. The user does not tick
  them off by hand; there is no personal to-do view in the MVP.
- **Topics** (pages for subjects that cross projects) come after the MVP.
- **Sources recorded in phase 1 are processed again** by the curator when phase 2
  arrives, so nothing recorded early is wasted.

## Navigation

The main window has a sidebar. Items that belong to a later phase are shown only
once that phase ships.

| Item | Content | Phase |
|------|---------|-------|
| **Home** | Dashboard: latest meetings, pending doubts, active projects, recent curator changes, recent people | 1 (tiles grow with each phase) |
| **Sources** | All sources with filters (meetings, notes, documents, without project) and search | 1 |
| **Projects** | Project pages | 2 |
| **People** | Person pages | 2 |
| **Doubts** | The review queue, one question at a time; the item shows how many are waiting | 2 |
| **Chat** | One global chat over the whole knowledge base | 3 |
| **Settings** | At the bottom of the sidebar | 1 |

Always available:

- **Record meeting** button at the top of the sidebar.
- **Command bar** (⌘K): search and commands.
- **Menu bar item**: record a meeting, new note, what is being processed, latest meetings.
- **Global shortcut** to start and stop recording without opening the app (⌥⌘R, set in
  Settings › Recording; one that macOS or Trama already uses is refused).
- Closing the window keeps Trama in the **menu bar**, out of the Dock, with recording
  and processing going on, until the user quits. Trama can open at login straight into
  the menu bar (Settings › General).
- **History** on every page generated by the curator.

## Screens

| Screen | Content | Phase |
|--------|---------|-------|
| **Home** | See *Navigation* | 1 |
| **Sources** | Table: title, type, date, duration, projects, status (for example "transcribing 62%") | 1 |
| **Meeting** | Title (generated, editable), summary and key points with timestamps, transcript with the two tracks (me / others) and the notes taken while recording. Audio player only if audio is kept. From phase 2: linked projects and people, and what the curator extracted | 1 |
| **Note** | Markdown editor with automatic saving | 1 |
| **Recording window** | Small floating window: timer, levels of the two tracks, a field for notes pinned to the current minute, stop | 1 |
| **Menu bar** | See *Navigation* | 1 |
| **First launch** | Microphone and system audio permissions, provider, transcription model download | 1 |
| **Settings** | Providers and models, transcription, recording, data and privacy, Claude (MCP), general | 1 |
| **Project page** | Goal, decisions, actions, requirements and open questions, each with citations; people, sources, timeline; history; "copy brief" | 2 |
| **Person page** | Role, projects, actions, where the person is mentioned | 2 |
| **Doubts** | One question at a time: the source, the evidence quoted with timestamps, the options with the curator's proposal, "skip for now" | 2 |
| **Chat** | Conversation list, answers with numbered citations and their sources, scope of the question | 3 |

## Main flows

| # | Flow | Phase | Steps |
|---|------|-------|-------|
| F1 | **First launch** | 1 | Microphone and system audio permissions → provider setup → transcription model download → ready. Every step can be postponed |
| F2 | **Record a meeting** | 1 | "Record" from the sidebar, the menu bar or the global shortcut → recording window (timer, levels, notes) → stop → local transcription (progress in the menu bar) → automatic summary and title → audio handled according to the retention setting → "Meeting ready" notification → meeting page |
| F3 | **Write a note** | 1 | ⌘N → editor → automatic saving |
| F4 | **Review a meeting** | 1 | Home or Sources → meeting → summary and transcript |
| F5 | **Clear the doubts** | 2 | Counter next to "Doubts" or a notification → one question at a time, with evidence → choice → next one |
| F6 | **Read a project** | 2 | Projects → page → click on a citation → the source opens at the right minute |
| F7 | **Undo a curator change** | 2 | History of the page or Home → "Undo" → the page updates |
| F8 | **Ask a question** | 3 | Chat → answer with citations → click → the source |
| F9 | **Import a document** | 3 | Drag the file onto the window or the Dock icon → processing → the document appears in Sources |
| F10 | **Connect Claude** | 3 | Settings → "Connect to Claude" → MCP configuration to copy, or installed automatically |

## Audio retention

The transcript is the source; audio is optional. A setting decides how long the
audio of a meeting is kept after a successful transcription:

| Option | Effect |
|--------|--------|
| **Never** (default) | Deleted as soon as the transcription succeeds |
| **7 days** / **30 days** | Deleted after that period |
| **Always** | Kept |

While the audio exists, the meeting page has a player. Without audio a meeting
cannot be transcribed again with a better engine, and a transcription error cannot be
checked by listening; the curator is not affected, since it works on transcripts.

## Wireframes

Low-fidelity wireframes of every screen above were drawn and validated by the
maintainer. Three Home variants were compared (feed of changes, dashboard, daily
brief); the **dashboard** was chosen. The wireframes are deliberately plain: the MVP
interface can stay simple, and the visual identity is designed separately in the
[visual direction](visual-direction.md).
