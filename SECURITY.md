# Security Policy

## Supported versions

Trama has not been released yet, so there are no supported versions.
This section will be updated with the first release.

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

Report them privately through GitHub:
[Report a vulnerability](https://github.com/lorenzotricaricoo/Trama/security/advisories/new).

Please include:

- a description of the problem and its impact;
- the steps to reproduce it;
- the affected version or commit, if known.

You will receive an answer as soon as possible. Once the problem is confirmed and
fixed, it will be disclosed through a GitHub security advisory.
